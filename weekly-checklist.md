# 16‑Week API Documentation Training Checklist

## Month 1 — Foundations
### Week 1
- Set up repo `api-writer-portfolio`
- Create VS Code workspace
- Install recommended extensions
- Clone repo using GitHub Desktop
- Create first commit (README)

### Week 2
- Learn API basics (HTTP verbs, status codes)
- Practice documenting 5 sample endpoints
- Create folder: `/docs/api-basics`
- Add API glossary

### Week 3
- Intro to Postman
- Build starter collection with 5 requests
- Add environment variables
- Document each request in Markdown

### Week 4
- Intro to OpenAPI
- Create starter YAML
- Document mock API entities
- Push weekly updates via GitHub Desktop

## Month 2 — Intermediate Workflows
### Week 5
- Branching strategy practice
- Create feature branches for docs
- Learn PR workflow

### Week 6
- Expand Postman collection
- Add tests using Postman scripts
- Export and document changes

### Week 7
- Deep‑dive OpenAPI (parameters, schemas)
- Add full schema definitions

### Week 8
- Build API website using Redoc or Markdown site
- Deploy via GitHub Pages

## Month 3 — Real‑World Scenarios
### Week 9
- Document authentication flows
- Add examples + curl snippets

### Week 10
- Error model documentation
- Create structured error table

### Week 11
- Versioning strategy
- Add version foldering in repo

### Week 12
- Extend mock API documentation
- Create full reference section

## Month 4 — Portfolio Build
### Week 13
- Build landing page for portfolio
- Add downloadable artifacts

### Week 14
- Finalize API website design
- Add search + navigation structure

### Week 15
- Create two sample case studies
- Improve code samples

### Week 16
- Final review + polishing
- Produce final PDF export
